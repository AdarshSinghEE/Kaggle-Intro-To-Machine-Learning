Kaggle - Intro to Machine Learning
This repository contains my solutions to the exercises from Kaggle's Intro to Machine Learning course.

📚 Course Overview
The course introduces the fundamentals of machine learning using Python and Scikit-learn. It covers the complete workflow from exploring data to building and evaluating machine learning models.

📝 Exercises
- Exercise 2 – Basic Data Exploration
- Exercise 3 – Your First Machine Learning Model
- Exercise 4 – Model Validation
- Exercise 5 – Underfitting and Overfitting
- Exercise 6 – Random Forests
- Exercise 7 – Machine Learning Competitions

🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

🎯 Purpose
This repository documents my progress through Kaggle Learn and serves as a reference for machine learning fundamentals.
